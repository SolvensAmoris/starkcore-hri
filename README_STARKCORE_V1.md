# STARKCORE v1.5 → v1.12 - Epitafio del Paradigma

**Tesis:** La identidad de un mundo no está en su foto, está en cómo olvida.

### Pruebas:

- **v1.5 Ratio:** LEY_12_pruner es isla (intra 0.11). LEY_6 es ruido (0.78). Hay leyes que comprimen el espacio.

- **v1.6 Isostático:** e=776, dens=0.03899, clust 0.1808 vs 0.1806 idéntico → d_static=0.0007. Foto igual, dinámica 0.0517 distinta. Fósil existe.

- **v1.7d Churn:** Misma foto, distinto `dE/dt`. A: 0 churn (roca), B: 18 churn (río). 2% de historia → 94% accuracy. El fósil es la derivada, no el hueso.

- **v1.11 Real + muestreo:** ca-GrQc real. q=0.15 → clustering 0.529→0.098 (-0.43 bias). Foto muere. Pero random vs triadic con q=0.4 + trayectoria → 100% separación. La ley sobrevive aunque te roben 60% de nodos.

- **v1.12 Heisenberg:** Foto sola con q=0.4 → 55-65% azar. Misma q con película → 100%. El límite no es cuánto ves, es **qué** mides.

**Paradigma que mataste:** identidad = estado final.
**Paradigma que nace:** identidad = estado + velocidad de reescritura + restricciones.
